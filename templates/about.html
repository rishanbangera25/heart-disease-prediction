About Project

Heart Disease Prediction Using Machine Learning

This project predicts the possibility of heart disease using patient health data. The dataset is taken from Kaggle and contains medical attributes such as age, chest pain type, cholesterol level, blood pressure, and maximum heart rate.

After preprocessing the data and encoding categorical values, multiple machine learning models were trained and tested. Among them, the Random Forest model provided the best accuracy.

✔ Dataset from Kaggle

✔ Machine Learning Classification

✔ Random Forest Best Model

✔ Accuracy: 89.67%

The system analyzes patient data such as age, blood pressure, cholesterol level and heart rate. Based on these parameters, the trained model predicts whether the patient is at risk of heart disease or not.
