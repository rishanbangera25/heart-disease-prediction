Project Methodology

Steps followed to build the Heart Disease Prediction System

1. Dataset Collection

The dataset used for this project was taken from Kaggle. It contains patient health parameters such as Age, Chest Pain Type, Cholesterol, Resting Blood Pressure, and Maximum Heart Rate.

2. Data Preprocessing

The dataset was cleaned and checked for missing values. Categorical variables were converted into numerical format using encoding techniques.

3. Feature Selection

Important health parameters such as Age, Cholesterol, Blood Pressure, and Heart Rate were used as features to train the machine learning models.

4. Train-Test Split

The dataset was divided into training and testing sets using an 80:20 ratio to evaluate model performance.

5. Model Training

Multiple machine learning algorithms were used including Logistic Regression, Decision Tree, Random Forest, and Support Vector Machine.

6. Model Evaluation

The models were evaluated using accuracy and confusion matrix. Random Forest achieved the highest accuracy of 89.67%.
